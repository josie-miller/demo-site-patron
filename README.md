# Patron demo website

A concise project page with a YouTube demo, GitHub links, and technical details.

Live site: https://josie-miller.github.io/demo-site-patron/

## Development

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000. No dependencies or build step are required.

- `index.html`: content, video embed, and links.
- `style.css`: responsive layout and branding.
- `script.js`: unused placeholder; no custom JavaScript is required.

GitHub Pages publishes from the root of `main`. Commits to `main` trigger deployment. The earlier private Sites preview is hosted separately.

App source: https://github.com/josie-miller/patron
