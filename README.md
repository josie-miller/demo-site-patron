# Patron project website

A static project showcase for Patron with an embedded YouTube demo, links to the iOS repository, interactive product examples, and an explanation of the Supabase backend.

## Preview locally

Run `python3 -m http.server 8000` in this directory, then visit http://localhost:8000.

No package installation or build step is required.

## Files

- `index.html`: page content, video embed, and project links.
- `style.css`: branding and responsive layout.
- `script.js`: archetype selector and rating demo.

## Project links

- App source: https://github.com/josie-miller/patron
- Video: https://youtu.be/6c4FlBPlHtQ
- Current private Sites deployment: https://patron-circle.indigodove3.chatgpt.site

The website does not connect to the live Supabase backend or collect form submissions. Contact links open an email draft. Google Fonts and the YouTube player require internet access.

## Hosting

Serve this directory with any static host. The current Sites deployment is managed separately; pushing to GitHub alone does not update that deployment.
