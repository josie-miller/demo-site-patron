01 / IOS APP

Museum circles, visit logs, ratings, and friends. Pending uploads are saved locally for retry.

Supabase

Authentication, Postgres data, and photo storage with signed URLs.

React + Vite

Member statistics, events, membership tiers, and CircleCode management.

04 / EVENT DATA

Python

A scheduled scraper imports museum listings into Supabase. Staff can also add events manually.
